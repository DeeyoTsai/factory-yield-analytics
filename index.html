工廠良率分析與缺陷辨識平台

Factory Yield Analytics & Defect Recognition Platform

把散落在人工表單、Excel VBA 巨集和數個老舊內部查詢頁的良率與缺陷資料， 整併成一個即時分析平台，再接上電腦視覺自動判缺陷。 A single real-time platform that consolidates yield and defect data previously scattered across paper forms, Excel/VBA macros and legacy internal pages — with a computer-vision model that classifies defect photos automatically.

  • React 19
  • Node · Express
  • Sequelize · MySQL
  • YOLOv10
  • Puppeteer

問題 The problem

現場缺陷資料靠人工填表，良率、機況、rework 分散在好幾個舊系統各查各的； 曝光機對位監控甚至還在用一支 Excel VBA 巨集開 IE 抓資料、算全距、寄信。 要看一個缺陷的全貌，得在五、六個畫面之間切換。 Defect data was logged on paper. Yield, equipment status and rework each lived in a separate legacy system. Exposure-alignment monitoring still ran as an Excel/VBA macro driving IE. Seeing one defect end to end meant hopping between half a dozen screens.

平台功能 What it does

缺陷檢驗登錄 Inspection logging

試算表式表格，一列一片玻璃、一欄一種缺陷；約 24 種缺陷類型加 S/M/L 尺寸計數，取代手寫紙本。

每日良率儀表板 Daily yield dashboard

三層鑽取：當日前五大缺陷 → 缺陷分布 → 單一缺陷分析（散佈圖、集中趨勢、rework、爐位）。一頁看完一個缺陷。

未結批良率 In-progress lot yield

還在製程中、尚未結批的批號也能看：依良率排序的水平長條，點進去就是同一套缺陷分析。

機台狀態時間軸 Equipment timeline

Gantt 式的設備動作與狀態歷史，依產線過濾。缺陷發生時對照當下機況。

曝光對位 SPC 監控 Alignment SPC monitor

取代 Excel VBA 巨集。無頭爬蟲抓資料，分段演算法把「真實漂移」和「換基準線造成的位移」分開，自動標出超規格欄位與離群片。

電腦視覺自動判缺陷 CV defect recognition

YOLOv10、18 類缺陷。複判照片經 FTP 跨網段送到 GPU 機台推論，結果回寫資料庫；用「人工修正比例」當模型健康度指標。

系統架構 Architecture

前後端分離的 SPA，加上一組排程爬蟲和一台跨網段的推論機台，全部寫進同一個資料庫。

推論機台在廠外、資料庫在廠內，中間隔一道網段，所以用 FTP 當橋接： 廠內端打包複判照片丟上去，GPU 端輪詢、跑完把結果寫回同一個資料庫。

# 工廠良率分析與缺陷辨識平台 — 作品展示

**Factory Yield Analytics &amp; Defect Recognition Platform — case study**

一頁式作品展示，介紹一套我獨力開發的全端製造分析平台：整合人工缺陷登錄、
由爬蟲建成的良率／缺陷資料倉，以及 YOLOv10 電腦視覺自動判缺陷。

A single-page case study for a full-stack manufacturing analytics platform I built solo:
manual defect logging, a scraper-fed yield/defect data warehouse, and a YOLOv10
computer-vision pipeline that classifies defect photos automatically.
